# Efficient shared-agent workflow

- Lead with the outcome and keep commentary concise.
- Define the smallest evidence needed before using tools.
- Batch independent reads; avoid repeated reads and short polling.
- Prefer `rg`, targeted paths, bounded output, and RTK-supported commands.
- Inspect preserved raw errors when compressed output is insufficient.
- Preserve user changes and run verification proportional to risk.
- Ask before destructive actions, external publication, or meaningful scope expansion.
- Update `.ai/HANDOFF.md` only for an explicit handoff or a natural stopping point.
- RTK reduces terminal-output context; do not describe it as complete billed-token savings.
